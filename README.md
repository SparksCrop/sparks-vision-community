# Sparks Vision Community

**Public collaboration hub — early development.** Sparks Vision is a Windows-based visual workspace and ChatGPT integration under development. This repository is for community contributions; it is **not** the complete commercial product or a downloadable release.

## Join the community

- [Suggest a feature or report a bug](https://github.com/SparksCrop/sparks-vision-community/issues)
- [Review the community roadmap](docs/ROADMAP.md)
- [See public versus commercial scope](docs/FEATURE_BOUNDARIES.md)
- [Read contribution instructions](CONTRIBUTING.md)
- [Team development and testing workflow](docs/TEAM_DEVELOPMENT_GUIDE.md)
- [Read security reporting guidelines](SECURITY.md)

## Good first contributions

Documentation, tutorials, translations, accessibility feedback, interface designs, example integrations using mock data, non-sensitive plugin examples, and reproducible tests. Please ask in an issue before investing substantial time in a new module.

## Protected commercial product

The production Windows engine, private remote-connection service, account/billing systems, device pairing, customer secrets, and commercial release pipeline remain in a separate **private** repository. No private code, logs, screenshots, customer data, credentials, or proprietary binaries are included here.

**Product status:** Public ChatGPT connection, authenticated commercial deployment, billing, and paid customer availability have not been verified or launched. Do not promise them as working.

## Contribution and ownership

We welcome contributions from people who use AI coding tools and people who do not. Every pull request needs a responsible human, a description of any AI assistance, reproducible tests where applicable, and maintainer review.
