# Sparks Vision Community — roadmap

Status: Proposed and subject to maintainer review.

## Stage 1 — Community foundation
- [x] Public repository, README, contribution guidelines, license, security guidance
- [ ] Issue labels: good first issue, documentation, design, accessibility, integration, bug
- [ ] Project board with Backlog / Ready / Working / Review / Done
- [ ] Public Discussions and contribution announcements
- [ ] Publish website community area linking here

## Stage 2 — First useful public building blocks
- [ ] Safe demo/mock of the six-tool MCP gateway contract
- [ ] Extension starter/example with a local test fixture (no real PC access)
- [ ] Open issue templates and accessibility component examples
- [ ] Platform-agnostic documentation and API behavior examples
- [ ] Public compatibility and documentation tests

## Stage 3 — Commercial integration readiness
- [ ] Private authenticated customer account/device pairing
- [ ] Separate website preview, staging, and production environments
- [ ] Security/secret/license audit before promoting any private source
- [ ] Build signed and reproducible commercial release
- [ ] Verify real ChatGPT integration in the intended supported host
- [ ] Finalize pricing, entitlement checks and customer support before enabling checkout

The public community repository cannot grant access to the private engine or paid features.
