# Security reporting

Sparks Vision interacts with powerful local computer functions. Do **not** post vulnerabilities, exploit steps, credentials, private screenshots, access tokens, or customer data in public issues or pull requests.

For sensitive findings, use GitHub's private vulnerability reporting if enabled for this repository. Otherwise, contact the repository maintainer privately through their GitHub profile to request a secure reporting channel, describing no exploit details publicly.

Do not scan, control, or test other people's machines or accounts without explicit permission. Public examples must use mocks and fixtures.
